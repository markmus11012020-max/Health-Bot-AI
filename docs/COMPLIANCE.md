# Compliance memo: 152-ФЗ и безопасность

Документ носит инженерный характер и не заменяет юридическую оценку.

## 1. Принципы обработки ПДн

- **Законность и справедливость:** обработка только для консультирования
  клиентов и допродаж.
- **Ограничение цели:** данные не используются для иных целей.
- **Минимизация:** в LLM уходит только анонимизированный текст.
- **Точность:** менеджер проверяет ответ перед отправкой клиенту.
- **Ограничение срока хранения:** сырые ПДн не сохраняются; аудит — по политике
  Заказчика.
- **Конфиденциальность и целостность:** TLS, шифрование at-rest, RBAC, аудит.

одного запроса и не попадает в логи, БД, кэш и трассировки.

## 3. Где могут возникнуть риски

| Риск | Мера |
|---|---|
| Сырые ПДн в промпте | Анонимизация до формирования промпта; тесты на утечку |
| Сырые ПДн в логах | Аудит пишет только метаданные и количество категорий |
| Сырые ПДн в кэше | Ключ и значение строятся по анонимизированному тексту |
| Prompt injection | Guardrails, системный промпт, модерация, red-team тесты |
| Медицинские утверждения | Запрещённые формулировки, дисклеймер, red flags |
| Зарубежная LLM | Юридическая оценка; предпочтение LLM в РФ |
| Доступ API | API-ключи, rate limit, RBAC, аудит |
| Утечка секретов | `.env` вне git, Vault/KMS, ротация |

## 4. Права субъектов ПДн

- доступ к информации об обработке;
- уточнение, блокирование, уничтожение;
- отзыв согласия;
- обращение в РКН и суд.

Для реализации прав необходимы: журнал обращений, идентификатор субъекта,
процедура удаления и срок ответа, установленный законом.

## 5. Инциденты

1. Обнаружение → классификация → локализация.
2. Уведомление ответственного за ИБ и Заказчика.
3. Уведомление РКН в установленные законом сроки.
4. Устранение, проверка, пост-инцидентный анализ.
5. Запись в журнал инцидентов.

## 6. Документы до пилота

- DPIA;
- политика обработки ПДн;
- согласие для пилотных пользователей;
- реестр субпроцессоров;
- реестр open-source-лицензий;
- план реагирования на инциденты;
- программа и методика испытаний.

## 7. Ограничение ответственности

Система не является медицинским изделием. Ответы носят информационный характер,
не заменяют консультацию врача. Менеджер обязан проверить ответ перед отправкой
клиенту.
