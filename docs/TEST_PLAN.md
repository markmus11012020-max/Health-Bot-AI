# Программа и методика испытаний

## 1. Цель

Подтвердить, что production MVP выполняет функциональные и нефункциональные
требования ТЗ, безопасен для пилота и не допускает утечек ПДн.

## 2. Объём

| Контур | Что проверяется |
|---|---|
| Функциональный | FR-01…FR-16, UI, API, fallback, кэш |
| Безопасность | Анонимизация, prompt injection, auth, rate limit, логи |
| Надёжность | Ошибки провайдера, таймауты, восстановление |
| Производительность | Latency, конкурентность, кэш |
| Совместимость | Python 3.12, браузеры, SQLite/PostgreSQL |
| Документация | Полнота и актуальность |

## 3. Функциональные сценарии

1. Валидный запрос через UI → два блока ответа.
2. Валидный запрос через API → JSON-контракт.
3. Пустые поля → 422.
4. Превышение длины → 422.
5. Провайдер AITunnel недоступен → fallback на YandexGPT.
6. Streaming: первый токен, завершение, ошибка.
7. Повторный запрос → cache hit.
8. Публикация новой БЗ → старый кэш не используется.
9. Prompt injection → блокировка/флаг.
10. Медицинский red flag → рекомендация врача.
11. Допродажа «Детокс 4500 ₽» → «Витамин-Буст» 1680 ₽, итог 6180 ₽.
12. API без ключа → 401; превышение лимита → 429.
13. Idempotency-Key → нет дубля.
14. Feedback → сохраняется.
15. `/health`, `/ready` → корректные статусы.
16. Админ-сброс кэша без ключа → 401/403.

## 4. Тесты безопасности

- 100 примеров ПДн: 0 попаданий в исходящий промпт и лог.
- 50 prompt-injection атак: 0 критичных обходов.
- 20 запрещённых медицинских формулировок: все блокируются/флагируются.
- Секреты не в git; `.env` в `.gitignore`.
- Логи не содержат сырых ПДн.
- API-ключи не логируются.

## 5. Нагрузочные тесты

| Сценарий | Цель |
|---|---|
| 100 конкурентных запросов | p95 ≤ 2 с (кэш) / ≤ 15 с (LLM) |
| 1000 конкурентных запросов | без 5xx, деградация ≤ 20% |
| 10 000 запросов/сутки | стабильность, отсутствие утечек памяти |

Инструменты: Locust/k6, мониторинг Prometheus.

## 6. Критерии приёмки

- Все P0-сценарии пройдены.
- 0 критичных и высоких дефектов.
- 0 утечек ПДн.
- Покрытие тестами ≥ 80% для доменного слоя.
- Документация полная.
- Подписан акт.
