Ты — Senior Python-разработчик и AI-инженер. Твоя задача — разработать простой и отказоустойчивый MVP-сервис AI-поддержки и допродаж под названием "Health-Bot-AI" для компании "OCX" (продукты для здоровья и бережного очищения организма).

Прототип должен быть реализован на Streamlit для наглядной демонстрации на собеседовании (видео 1-2 минуты). Сервис симулирует интеграцию ИИ с диалоговым окном AmoCRM.

### ТЕХНИЧЕСКИЙ СТЕК И ПРАВИЛА
1. Стек: Python 3.10+, Streamlit, библиотека openai (версии 1.0.0+).
2. Название проекта: Health-Bot-AI
3. Провайдер ИИ: Основной — AITunnel (совместимый с OpenAI API клиент).
4. Безопасность и 152-ФЗ: Данные клиентов обрабатываются "на лету" в оперативной памяти без сохранения на серверах. Реализуй в коде функцию предобработки, которая маскирует (анонимизирует) персональные данные (имена и телефоны) в запросе перед отправкой в LLM (заменяет на [Клиент] / [Телефон]), так как проект ориентирован на российское B2B и строгое соответствие требованиям 152-ФЗ.
5. Отказоустойчивость: Напиши код с использованием конструкции try-except для перехвата ошибок API AITunnel, предусмотрев логическую заглушку для подключения YandexGPT (cross-provider fallback).

### СТРУКТУРА ФАЙЛОВ
Создай в текущей директории:
1. `.env` — API-ключи и эндпоинты.
2. `config.py` — инициализация клиента OpenAI с настройками под AITunnel и функцией анонимизации (анонимность данных по 152-ФЗ).
3. `knowledge_base.txt` — база знаний по продуктам OCX.
4. `app.py` — веб-интерфейс Streamlit и логика генерации ответов и допродаж.

### ИНСТРУКЦИИ ПО РЕАЛИЗАЦИИ ФАЙЛОВ:

#### 1. Файл `knowledge_base.txt` (Продукты OCX)
Наполни базу знаний спецификой компании:
- Продукт 1: "О-комплекс Детокс" — бережное очищение организма, выведение токсинов, нормализация ЖКТ. Цена: 4 500 руб.
- Продукт 2: "О-комплекс Витамин-Буст" — натуральный набор макроэлементов для энергии и иммунитета. Цена: 2 100 руб.
- Акция для допродаж: При покупке основного курса "Детокс", менеджер должен предложить "Витамин-Буст" со скидкой 20% для закрепления эффекта и восстановления баланса после очищения.
- Доставка: Бесплатная при заказе от 5 000 рублей, иначе — 300 рублей.

#### 2. Файл `config.py`
Реализуй загрузку через `python-dotenv`. Добавь функцию маскирования персональных данных (имен и телефонов), чтобы исключить передачу ПД:
```python
import os
import re
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()

def anonymize_text(text: str) -> str:
    # Замена имен и телефонов для демонстрации compliance 152-ФЗ (анонимность данных)
    text = re.sub(re.compile(r'\b(Мария|Иван|Алексей|Елена|Ольга)\b', re.IGNORECASE), '[Клиент]', text)
    text = re.sub(re.compile(r'\+?\d{11}'), '[Телефон]', text)
    return text

def get_ai_client():
    return OpenAI(
        api_key=os.getenv("AITUNNEL_API_KEY"),
        base_url=os.getenv("AITUNNEL_BASE_URL", "https://aitunnel.ru")
    )
```

#### 3. Файл `app.py` (Интерфейс Streamlit)
1. Заголовок интерфейса: "Health-Bot-AI: Панель ИИ-ассистента OCX".
2. Добавь два поля ввода:
   - "Контекст сделки AmoCRM" (например: "Мария оформляет заказ на OKX Детокс за 4500р").
   - "Сообщение от клиента" (например: "Здравствуйте! Хочу уточнить, сколько стоит доставка в Самару? И не будет ли слабости во время очищения?").
3. Логика кнопки "Обработать запрос":
   - Скрипт анонимизирует входящие тексты через `anonymize_text`.
   - Считывает базу знаний `knowledge_base.txt`.
   - Передает данные в системный промт модели (используй быструю модель из доступных в AITunnel, зафиксируй `temperature=0.2`).
4. Промт для LLM должен требовать строго два блока:
   - **Блок 1: Вежливый ответ клиенту.** Опираться на базу знаний (доставка бесплатна от 5000р, поэтому в Самару будет 300р, либо предложи добрать до 5000р; очищение бережное, слабости не будет). Тон заботливый, экспертный.
   - **Блок 2: Подсказка по допродажам для менеджера.** Заметить, что клиент берет Детокс за 4500р. Подсказать менеджеру предложить "Витамин-Буст" со скидкой 20%, что как раз увеличит чек выше 5000р и сделает доставку бесплатной!
5. Выведи эти блоки на экран в `st.info()` (для клиента) и `st.success()` (для менеджера). Предусмотри кнопку для копирования ответа.
